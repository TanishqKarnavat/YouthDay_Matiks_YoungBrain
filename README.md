# Matiks Brain_Age

A playful brain performance experience

Test your memory, reasoning, calculation, and problem solving skills through a series of interactive challenges.

## What it does

Matiks Young Brain measures how you perform across different types of cognitive challenges.

The experience includes:

**Memory**
Remember patterns and information, then recreate or recall them.

**Remember and Reason**
Use information you have seen earlier and apply logical reasoning to answer questions.

**Zip**
Connect numbered cells in order while filling the entire grid.

**Patches**
Divide the grid into valid rectangular patches based on the numbered clues.

Your result takes into account:

Correct answers
Time taken
Average response time

The result is used as part of the overall Brain Age calculation.

## Built for mobile

The experience is designed primarily for mobile devices with responsive layouts and touch friendly interactions.
